       - Pre-seed standard mock requisitions for Ahmednagar district (e.g. FMD vesicular swab from Ashwi Budruk).
       - SQLite local table `lab_requisitions` with schema migrations.
       - `calculateColdChainMetrics(collectedAtIso: string, currentTempC: number): ColdChainMetrics`:
         - 48h SLA calculation.
         - Remaining hours & minutes.
         - Progress percent: `min(100, (elapsed / 48) * 100)`.
         - Health status: `OPTIMAL` (2°C–8°C), `WARNING` (8°C–12°C or >36h), `BREACHED` (>12°C or >=48h).

       - `logTemperature(requisitionId, tempC, location)`: logs temperature checkpoint.
       - `submitResult(requisitionId, testType, result, notes)`: updates status to `LAB_CONFIRMED` if positive.
       - `generateQrPayload(req: LabRequisition)`: returns JSON string formatted for scanner.
    2. Create `mobile/src/tests/labService.test.ts`:

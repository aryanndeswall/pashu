  <name>Task 1: Build Web-GIS Schemas & Epidemiological Services</name>
  <files>backend/app/schemas/gis.py, backend/app/schemas/__init__.py, backend/app/services/gis_service.py, backend/app/services/__init__.py</files>
  <read_first>.planning/phases/10-web-gis-command-center-idsp-bridge-sih-demo-simulation/10-RESEARCH.md, backend/app/schemas/cluster.py</read_first>
  <action>
    1. Create `backend/app/schemas/gis.py`:
       - `EpiCurvePoint`: date (str YYYY-MM-DD), day_index (1..14), suspected_cases, confirmed_cases, mortality_count, reproduction_number (Rt)
       - `EpiCurveResponse`: district_name, syndrome_code, total_suspected, total_confirmed, total_deaths, peak_day, current_rt, points: List[EpiCurvePoint]
       - `MarketClosureMemoRequest`: cluster_id, district_name, magistrate_name, affected_villages: List[str], closed_haats: List[str], quarantine_checkpoints: List[str]
       - `MarketClosureMemoResponse`: memo_reference_no, issued_at, act_citation, order_headline_mr, order_headline_en, full_memo_marathi, full_memo_english, affected_villages, closed_haats
       - `IdspDispatchPayload`: cluster_id, syndrome_code, suspected_disease, district_name, human_contacts_flagged: int, risk_level: str
       - `IdspDispatchResponse`: dispatch_id, status, target_agency, dispatched_at, fhir_message_id, recommended_actions: List[str]
       - `SimulationStep`: step_number (1..7), step_title, step_title_mr, component, status, metrics: dict
       - `SimulationResponse`: scenario_name, total_steps, execution_time_ms, steps: List[SimulationStep], final_containment_status
    2. Export schemas in `backend/app/schemas/__init__.py`.
    3. Create `backend/app/services/gis_service.py`:
       - `generate_14_day_epi_curve(district: str = "Ahmednagar", syndrome: str = "SYN_VESICULAR") -> EpiCurveResponse`:
         - Builds 14-day rolling time-series up to current date.
         - Simulates standard epidemiological bell curve showing early exponential rise (Rt 2.8), peak around Day 6-7, and rapid decline (Rt 0.65) following 72h ring-vaccination intervention.
       - `generate_market_closure_memo(payload: MarketClosureMemoRequest) -> MarketClosureMemoResponse`:
         - Generates official bilingual administrative order citing Sections 6, 10, and 20 of PCICDA Act 2009.
       - `dispatch_idsp_alert(payload: IdspDispatchPayload) -> IdspDispatchResponse`:
         - Emits inter-agency syndromic notification for human fever contact tracing.
       - `run_ahmednagar_simulation() -> SimulationResponse`:
         - Generates the 7-step Ahmednagar FMD outbreak presentation journey.
    4. Export `gis_service` in `backend/app/services/__init__.py`.
  </action>
  <verify>
    Run `python -c "from app.schemas.gis import EpiCurveResponse; from app.services.gis_service import gis_service; print('GIS services valid')"`
  </verify>

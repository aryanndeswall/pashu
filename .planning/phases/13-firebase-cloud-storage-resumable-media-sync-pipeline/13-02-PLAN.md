# Plan 13-02: Mobile Firebase Storage & Resumable Media Sync Integration

**Phase:** 13  
**Plan:** 02 of 02  
**Requirement:** `CLOUD-02`  
**Goal:** Connect the mobile two-phase sync queue to the cloud media storage pipeline, uploading lesion WebP images and Indic audio recordings with network-aware gating (4G/Wi-Fi only) and persisting remote `gs_uri` / `https_url` in SQLite.

---

## Proposed Changes

### 1. Types & Config
- **File [MODIFY]:** `mobile/src/types/sync.ts`
  - Update `MediaQueueItem` to include `gs_uri?: string | null`, `https_url?: string | null`, `upload_progress?: number`.
  - Update `SyncResult` with media details if needed.
- **File [MODIFY]:** `mobile/src/config/api.ts`
  - Add helper functions `getSyncMediaSignedUrlEndpoint()` and `getSyncMediaItemEndpoint(mediaId: string)`.

### 2. Client Media Storage Service
- **File [NEW]:** `mobile/src/services/mediaStorageClient.ts`
  - Provides media upload helper with progress tracking and network timeout.
  - Formulates multipart or base64 JSON payload to send to `/api/v1/sync/media`.
  - Handles direct PUT upload when presigned upload URL is supplied.

### 3. Sync Engine Service Integration
- **File [MODIFY]:** `mobile/src/services/syncEngineService.ts`
  - Update `processSyncQueue` Phase 2 media loop:
    - Transmit `media_data` (WebP / audio base64) to cloud storage endpoint.
    - Extract returned `gs_uri` and `https_url`.
    - Update `media_sync_queue` table with status `COMPLETED`, `synced_at`, `gs_uri`, and `https_url`.
    - If upload fails, increment `retry_count` and mark `FAILED_RETRY` without losing local media data.
  - Maintain 2G/EDGE freeze (only flush media on 4G/5G/Wi-Fi).

### 4. UI / Drawer Enhancements
- **File [MODIFY]:** `mobile/src/components/sync/SyncQueueDrawer.tsx`
  - Display media item sync status (e.g. "Lesion Photo [Synced ✓]" or "Audio Note [Pending 4G]").
  - Show remote URL preview if synced.

### 5. Automated Unit Tests
- **File [NEW]:** `mobile/src/tests/mediaSync.test.ts`
  - Test Phase 2 media synchronization with payload transmission.
  - Test SQLite status updates when media upload succeeds.
  - Test network tier gating (2G vs 4G/WiFi).
  - Test retry mechanism on network timeout.

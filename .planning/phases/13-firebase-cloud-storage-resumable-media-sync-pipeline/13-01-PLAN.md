# Plan 13-01: Backend Firebase Admin SDK, Cloud Storage Pipeline, and Signed URL Services

**Phase:** 13  
**Plan:** 01 of 02  
**Requirement:** `CLOUD-02`  
**Goal:** Implement backend Firebase Cloud Storage integration using Firebase Admin / Google Cloud Storage SDK with resilient local fallback, signed URL generation, media database persistence, and Gemini `gs://` URI triage ingestion.

---

## Proposed Changes

### 1. Dependencies & Configuration
- **File:** `backend/requirements.txt`
  - Add `firebase-admin>=6.5.0` (or `google-cloud-storage>=2.18.0`).
- **File:** `backend/app/config.py`
  - Ensure `FIREBASE_CREDENTIALS_PATH` and `FIREBASE_STORAGE_BUCKET` are fully typed with helper property `has_firebase_credentials`.

### 2. Storage Service Layer
- **File [NEW]:** `backend/app/services/storage_service.py`
  - Define `StorageUploadResult` (media_id, gs_uri, https_url, size_bytes).
  - Abstract base class `BaseStorageService`.
  - `FirebaseStorageService`: Initializes Firebase app with `credentials.Certificate` and `storage.bucket(settings.FIREBASE_STORAGE_BUCKET)`. Supports uploading bytes, generating v4 signed GET and PUT URLs, and canonical `gs://` references.
  - `LocalStorageService`: Fallback engine saving files to `backend/uploads/media/` and returning local stream URLs when credentials are not configured.
  - Factory function `get_storage_service()`.

### 3. Database Model & Schemas
- **File [MODIFY]:** `backend/app/models/incident.py`
  - Define `IncidentMedia` model (`media_id`, `sync_id`, `report_id`, `media_type`, `file_size_kb`, `gs_uri`, `https_url`, `created_at`).
- **File [MODIFY]:** `backend/app/models/__init__.py`
  - Export `IncidentMedia`.
- **File [MODIFY]:** `backend/app/schemas/sync.py`
  - Update `MediaSyncRequest` to accept `media_data` (base64 string or binary), `content_type`, `report_id`.
  - Update `MediaSyncResponse` with `gs_uri` and `https_url`.
  - Add `SignedUrlRequest` and `SignedUrlResponse`.

### 4. API Endpoints
- **File [MODIFY]:** `backend/app/api/v1/sync.py`
  - Update `POST /media`: Ingests binary payload, uses `storage_service` to persist asset, creates `IncidentMedia` row in database, returns `gs_uri` and `https_url`.
  - Add `POST /media/signed-url`: Generates presigned PUT URL for direct client upload.
  - Add `GET /media/{media_id}`: Retrieves stored media details and streams asset or redirects.

### 5. Gemini Multimodal Ingestion
- **File [MODIFY]:** `backend/app/schemas/triage.py`
  - Add `photo_uri: Optional[str] = None` and `audio_uri: Optional[str] = None` to `TriageRequest`.
- **File [MODIFY]:** `backend/app/services/triage_service.py`
  - If `photo_uri` is present and starts with `gs://`, pass `types.Part.from_uri(file_uri=request.photo_uri, mime_type="image/webp")` directly to Gemini.

### 6. Automated Testing
- **File [NEW]:** `backend/tests/test_storage.py`
  - Test storage service initialization (Firebase vs Local fallback).
  - Test `/api/v1/sync/media` binary upload and `IncidentMedia` persistence.
  - Test `/api/v1/sync/media/signed-url` presigned URL generation.
  - Test `TriageRequest` with `gs://` URI.

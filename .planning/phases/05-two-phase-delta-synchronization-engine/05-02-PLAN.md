  <files>mobile/src/store/syncStore.ts, mobile/src/tests/syncStore.test.ts</files>
  <read_first>mobile/src/services/networkService.ts, mobile/src/services/syncEngineService.ts, mobile/src/database/sqliteConnection.ts</read_first>
  <action>
    1. Create `mobile/src/store/syncStore.ts`:
       - State:
         - `networkTier: NetworkTier`
         - `isSyncing: boolean`
         - `pendingCount: number`
         - `phase1Count: number`
         - `completedCount: number`
         - `queueItems: QueueItem[]`
         - `lastSyncedAt: string | null`
         - `isDrawerOpen: boolean`
       - Actions:
         - `initSyncStore()`: Reads initial network status via `networkService.getNetworkState()`, subscribes to `networkService.onNetworkChange()`, and calls `refreshQueue()`. Automatically calls `triggerSync()` if reconnecting from offline to online.
         - `refreshQueue()`: Queries `SELECT * FROM offline_sync_queue ORDER BY priority DESC, created_at DESC`. Calculates counts and updates state.
         - `triggerSync()`: Sets `isSyncing = true`, executes `syncEngineService.processSyncQueue(networkTier)`, plays tactile feedback via `hapticsService`, refreshes queue, updates `lastSyncedAt`, and resets `isSyncing = false`.
         - `setDrawerOpen(isOpen: boolean)`: Toggles sync drawer.
         - `setSimulatedNetworkTier(tier: NetworkTier | null)`: For hackathon demo and testing.
    2. Create `mobile/src/tests/syncStore.test.ts`:
       - Tests `initSyncStore` binds network listeners.
       - Tests `refreshQueue` accurately counts pending vs Phase 1 vs completed items.
       - Tests `triggerSync` invokes `syncEngineService.processSyncQueue` and sets `lastSyncedAt`.
  </action>
  <verify>
    Run `npm --prefix mobile test -- src/tests/syncStore.test.ts` to confirm store behavior.
  </verify>
  <acceptance_criteria>
    - `mobile/src/store/syncStore.ts` exports `useSyncStore`
    - All tests in `mobile/src/tests/syncStore.test.ts` pass with 100% green assertions
  </acceptance_criteria>

    Sync store implemented with reactive network hooks and automated tests.

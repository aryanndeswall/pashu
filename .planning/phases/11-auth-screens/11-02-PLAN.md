       - Props: `mode: 'setup' | 'unlock'`

         - 4 Animated PIN indicator dots (`● ● ○ ○`) filling on input.
         - For `setup` mode: Step 1 (Enter PIN) ➔ Step 2 (Confirm PIN) with error shake animation if mismatch.
         - For `unlock` mode: Displays remaining attempts if incorrect; displays 60s countdown timer when locked out.
       - Custom 3x4 Numeric Keypad:
         - Buttons 1 to 9, backspace icon, 0, and clear.
         - Circular touch buttons with minimum 64px touch target.
         - Light haptic vibration (`hapticsService.hapticLight()`) on every number tap.
         - Error haptic vibration on incorrect attempt.

<threat_model>
| Threat ID | Category | Component | Description | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-03-01 | Denial of Service | Camera Service | Uncompressed 12MP+ camera photos exhausting WebView RAM and crashing budget Android devices | Implement offscreen Canvas scaling to max 1280x720 (720p) at 75% quality, automatically stepping down to 60% if output exceeds 300 KB. |
| T-03-02 | Denial of Service / Storage | Voice Service | Infinite background audio recording consuming all device disk storage | Enforce a hard 30-second timeout that automatically stops recording and finalizes the audio buffer. |
| T-03-03 | Tampering / Invalid Data | Location Service | Corrupt/spoofed GPS coordinates causing inaccurate spatial clustering | Validate latitude (8.0°–37.5°N) and longitude (68.0°–97.5°E) bounds, check accuracy radius, and snap to verified LGD codes in `local_lgd_hierarchy`. |
| T-03-04 | Configuration | AndroidManifest.xml | Missing runtime permissions causing app crashes on native Android execution | Declare `CAMERA`, `ACCESS_FINE_LOCATION`, and `RECORD_AUDIO` permissions in `AndroidManifest.xml`. |
</threat_model>

    2. In `mobile/android/app/src/main/AndroidManifest.xml`, insert the necessary hardware permissions:
       ```xml
       <!-- Camera Permissions -->
       <uses-permission android:name="android.permission.CAMERA" />
       <uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
       <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" android:maxSdkVersion="32" />
       <uses-feature android:name="android.hardware.camera" android:required="false" />

       <!-- Geolocation Permissions -->
       <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
       <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
       <uses-feature android:name="android.hardware.location.gps" android:required="false" />

       <!-- Audio Recording Permissions -->
       <uses-permission android:name="android.permission.RECORD_AUDIO" />
       <uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
       <uses-feature android:name="android.hardware.microphone" android:required="false" />
       ```
    3. In `mobile/src/services/cameraService.ts`, implement `CameraService`:
       - `captureLesionPhoto(source?: 'camera' | 'photos'): Promise<CapturedPhoto>`
       - Image compression helper `compressToWebP(imageSource: string | HTMLImageElement, maxDimension = 1280, initialQuality = 0.75): Promise<CompressedImageResult>`:
         - Calculates proportional bounding dimensions for max 1280x720.
         - Draws to an offscreen `<canvas>`.
         - Converts to `'image/webp'` data URL.
         - Checks byte length (base64 length * 0.75).
         - If size > 300 * 1024 bytes (300 KB), re-renders at 0.60 quality.
         - Returns `{ dataUrl, format: 'image/webp', sizeBytes, width, height, timestamp }`.
       - Web fallback: supports file input / mock image capture for unit tests and browser debugging.
    4. Create `mobile/src/tests/cameraService.test.ts`:
       - Tests dimension scaling algorithm preserves aspect ratios (16:9, 4:3, 1:1) within 1280x720.
       - Tests payload size calculation and format verification (`image/webp`).
       - Tests adaptive quality dial-down when simulated payload exceeds 300 KB limit.
  </action>

    1. In `mobile/src/services/voiceService.ts`, implement `VoiceService`:
       - Manages recording state (`isRecording: boolean`, `durationSeconds: number`, `recordedAudioUrl: string | null`, `audioBase64: string | null`, `mimeType: string`).
       - `startRecording(onTick?: (seconds: number) => void): Promise<boolean>`:
         - Checks/requests microphone permission via `VoiceRecorder.hasAudioRecordingPermission()` / `VoiceRecorder.requestAudioRecordingPermission()` or browser `navigator.mediaDevices.getUserMedia`.
         - Starts audio recording.
         - Starts a 100ms interval timer tracking elapsed duration up to 30.0 seconds.
         - Automatically invokes `stopRecording()` when duration reaches 30 seconds (SYN-02).
       - `stopRecording(): Promise<RecordedAudioResult | null>`:
         - Stops recorder, clears timer, extracts base64 audio data and mime type (`audio/aac` / `audio/webm`).
         - Generates playable object URL / data URL for playback.
       - `playAudio(audioUrl?: string): Promise<void>` / `stopPlayback(): void` using HTML5 Audio instance.
       - `resetAudio(): void` to clear current recording.
    2. In `mobile/src/services/locationService.ts`, implement `LocationService`:
       - `getCurrentLocation(): Promise<LocationCoordinates>`:
         - Calls `Geolocation.getCurrentPosition({ enableHighAccuracy: true, timeout: 10000, maximumAge: 3000 })` with web fallback (`navigator.geolocation.getCurrentPosition`).
         - Returns `{ latitude, longitude, accuracy, timestamp }`.
       - `calculateHaversineDistance(lat1: number, lon1: number, lat2: number, lon2: number): number`:
         - Implements standard Haversine formula returning distance in kilometers.
       - `snapToNearestLgdVillage(lat: number, lon: number): Promise<SnappedLgdResult>`:
         - Queries `local_lgd_hierarchy` from `dbService.query('SELECT * FROM local_lgd_hierarchy')`.
         - If database returns empty or in-memory, loads fallback LGD seed records.
         - Computes distance to all villages and returns the minimum distance record `{ lgd_code, village_name, block_name, district_name, distanceKm, isAccurate: distanceKm <= 25 }`.
       - `getAllLgdVillages(): Promise<LgdVillageRecord[]>`:
         - Returns all available villages for manual dropdown override.
    3. Create `mobile/src/tests/voiceService.test.ts`:
       - Tests recording start, duration tracking, 30s auto-stop callback, and audio reset.
       - Tests MIME type handling and duration bounding.

# Phase 3.1: Multi-Role Authentication Shell (Doctor, Consumer, Admin) & SIH Demo Role-Switcher - Context

**Gathered:** 2026-09-03  
**Status:** Ready for planning & execution  
**Source:** User Direction via `/gsd-discuss-phase 3.1`

<domain>
## Phase Boundary

Phase 3.1 establishes the multi-role identity and authorization foundation across the mobile application:
- **3 Target Personas**:
  - **Consumer / Livestock Owner (पशुपालक)**: Simplified vernacular UI (Marathi/Hindi), 1-tap syndromic reporting with photo & voice, digital cattle passbook (Pashu Aadhaar), local Pashu Sakhi helpline (`1962`).
  - **Doctor / Field Veterinarian & Pashu Sakhi (पशुवैद्य)**: Clinical diagnostic mode, 8-syndrome triage with differential diagnosis, zero-tolerance Anthrax biohazard protocol, e-LRF lab requisition generator with QR codes.
  - **Admin / District Animal Husbandry Officer (जिल्हा अधिकारी)**: Executive surveillance command, real-time outbreak alerts, 1-5-10 km geodetic containment zone overview, 1-click administrative market closure order generation.
- **Login & Role Selection Screen (`RoleSelectionView.tsx`)**: 3 high-contrast UI-UXmax cards with 52px thumb targets, bilingual Devanagari labels, and biometric/quick-pass access.
- **Top Header Demo Role-Switcher Bar**: A sleek, 1-click role switcher pill visible in `HeaderBar.tsx`, enabling instantaneous switching between Consumer, Doctor, and Admin modes during a live 5-minute SIH hackathon jury presentation without typing passwords.
- **Persistent Auth Store (`useAuthStore.ts`)**: Stores `activeRole: 'consumer' | 'doctor' | 'admin'`, user metadata, assigned district/taluka (Ahmednagar/Rahuri), and persists state to SQLite for 100% offline reboot.
- **Role-Filtered Navigation & Views**: Bottom navigation tabs dynamically filter based on role (e.g. Labs & Clinical Triage visible to Doctor; Executive Outbreaks visible to Admin; Simple Passbook visible to Consumer) with haptic feedback confirming transitions.
</domain>

  - `admin`: डॉ. एस. के. कुलकर्णी (Dr. S. K. Kulkarni), जिल्हा पशुसंवर्धन अधिकारी (DVO), जिल्हा: अहमदनगर, अधिकारी कोड: DVO-AHM-001.

### 2. Login Screen & Instant Quick-Access
- **D-02: RoleSelectionView.tsx Structure:**
  - 3 large, sunlight-readable persona cards with 52px touch targets (`.field-touch-target`).
  - Card 1 (Farmer/Consumer): Emerald accent (`#059669`), 👨‍🌾 icon, Marathi description.
  - Card 2 (Vet/Doctor): Blue accent (`#2563eb`), 🩺 icon, clinical description.
  - Card 3 (Admin/DVO): Purple accent (`#7c3aed`), 🏛️ icon, executive authority description.
  - Tapping "हा रोल निवडा (Select this Role)" immediately logs into that persona, saves the session to SQLite, and updates the UI with haptic vibration.

### 3. Top Header Demo Switcher for SIH Jury Presentation
- **D-03: 1-Click Header Role Switcher Pill:**
  - Embedded in `HeaderBar.tsx` next to the sunlight toggle.
  - Shows an unmistakable badge: `[ 👨‍🌾 पशुपालक ]` / `[ 🩺 पशुवैद्य ]` / `[ 🏛️ जिल्हा अधिकारी ]`.
  - Tapping it pops open a bottom drawer (`FluidDrawer`) with 1-tap switching between all 3 personas, enabling effortless demonstrations to hackathon judges without typing credentials.

### 4. Role-Filtered Navigation Matrix
- **D-04: Dynamic Tab Rendering (`BottomBar.tsx`):**
  - **Consumer**: 3 tabs (`report` [नोंदणी], `dashboard` [स्थानिक स्थिती], `animals` [माझे पशु]) + Helpline SOS.
  - **Doctor**: 4 tabs (`report` [८ लक्षणे], `dashboard` [डॅशबोर्ड], `animals` [पशु आधार], `labs` [प्रयोगशाळा]) + Anthrax SOS.
  - **Admin**: 4 tabs (`dashboard` [कमांड सेंटर], `report` [क्लिनिकल सारांश], `animals` [नोंदणी], `labs` [लॅब पडताळणी]) + Containment SOS.
  - **Safety Guard:** If switching to Consumer while on the `labs` tab, automatically redirect to `report` tab to prevent unauthorized access states.

### 5. Offline Durability
- **D-05: SQLite Session Persistence:**
  - Table `auth_session (id TEXT PRIMARY KEY, active_role TEXT NOT NULL, display_name TEXT NOT NULL, district TEXT, block TEXT, updated_at TEXT)`.
  - Upon app launch, `useAuthStore.initSession()` restores the last active persona from SQLite.
</decisions>

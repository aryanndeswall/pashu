# Phase 3.1: Multi-Role Authentication Shell (Doctor, Consumer, Admin) - Pattern Map

**Phase:** 03.1  
**Status:** Ready for planning  
**Analogs in Codebase:**

---

## 1. Store Pattern: `useNavigationStore.ts`
- **Analog:** `mobile/src/store/navigationStore.ts` (Zustand store with setter actions).
- **Application:** Create `mobile/src/store/authStore.ts` managing:
  - `activeRole: 'consumer' | 'doctor' | 'admin'`
  - `userProfile: UserProfile`
  - `switchRole(role)` action triggering `hapticsService.hapticLight()` and updating SQLite session.

---

## 2. Header Bar Integration Pattern: `HeaderBar.tsx`
- **Analog:** `mobile/src/components/common/HeaderBar.tsx` (renders app title, offline indicator, and sunlight theme toggle).
- **Application:** Add an interactive role pill badge in `HeaderBar.tsx` that opens the demo role switcher drawer or switches role with 1 tap.

---

## 3. Dynamic Navigation Tab Filtering: `BottomBar.tsx`
- **Analog:** `mobile/src/components/navigation/BottomBar.tsx` (maps tabs to buttons).
- **Application:** Read `activeRole` from `useAuthStore` to filter tab items before rendering.

## 2. Technical Architecture

### A. Persistent Auth Store (`useAuthStore.ts`)
- Implemented with Zustand.
- Manages:
  - `activeRole: 'consumer' | 'doctor' | 'admin'` (defaults to `'consumer'`)
  - `userProfile: UserProfile`
  - `switchRole(role: UserRole)`: Updates state, persists to SQLite `auth_session`, and triggers haptics.
  - `loadPersistedSession()`: Queries SQLite on app boot to restore the last active persona.

### B. SQLite Session Table
```sql
CREATE TABLE IF NOT EXISTS auth_session (
  id TEXT PRIMARY KEY,
  active_role TEXT NOT NULL,
  display_name TEXT NOT NULL,
  district TEXT NOT NULL,
  block TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
```

### C. SIH 1-Click Header Demo Role-Switcher
- Placed directly in `HeaderBar.tsx`.
- Displays the active role pill with iconic indicator:
  - `👨‍🌾 पशुपालक` / `🩺 पशुवैद्य` / `🏛️ जिल्हा अधिकारी`.
- Tapping the pill triggers an instant, fluid bottom drawer (`FluidDrawer`) listing the 3 personas with a 1-tap switch button.
- Immediate tactile feedback (`hapticsService.hapticLight()`) confirms role transition without reload.

### D. Dynamic Navigation Filtering (`BottomBar.tsx`)
- The navigation store and `BottomBar.tsx` read `useAuthStore.getState().activeRole`.
- Tabs dynamically hide/show based on the role access matrix.
- If switching from Doctor to Consumer while on the `labs` tab, the navigation automatically resets `activeTab` to `'report'` to prevent invalid access states.

## 3. Validation Architecture

### Unit & Integration Test Suite (`vitest`)
1. **Auth Store Tests (`authStore.test.ts`):**
   - Tests initial state defaults to `'consumer'`.
   - Tests `switchRole('doctor')` and `switchRole('admin')` updates state and profiles.
   - Tests SQLite session persistence and restoration upon reload.
2. **Role Selection & Header Switcher Tests (`RoleSelection.test.tsx`):**
   - Tests rendering of all 3 persona cards with Devanagari labels and 52px touch targets.
   - Tests 1-tap switching updates the header badge and emits haptic feedback.
3. **Role-Filtered Navigation Tests (`roleNavigation.test.tsx`):**
   - Verifies `labs` tab is hidden for `consumer` and visible for `doctor`/`admin`.
   - Verifies tab auto-redirection when switching from a restricted tab.

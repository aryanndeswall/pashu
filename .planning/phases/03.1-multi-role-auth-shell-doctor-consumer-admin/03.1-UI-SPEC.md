# Phase 3.1 — UI Design Contract: Multi-Role Authentication Shell & SIH Demo Role-Switcher

> Visual and interaction design contract for Pashu-Suraksha's 3-role persona cards, header demo role-switcher pill, and dynamic navigation filtering.

---

## Executive Summary & Design Principles

1. **3 Distinct Persona Cards**:
   - 👨‍🌾 **पशुपालक (Farmer / Consumer)**: High vernacular clarity, Emerald theme (`#059669`).
   - 🩺 **पशुवैद्य (Doctor / Field Vet)**: Clinical precision, Royal Blue theme (`#2563eb`).
   - 🏛️ **जिल्हा अधिकारी (District Admin)**: Executive authority, Deep Purple/Indigo theme (`#7c3aed`).
2. **SIH 1-Click Header Demo Switcher**:
   - HeaderBar features an unmistakable persona badge pill (e.g. `[ 👨‍🌾 पशुपालक ]`).
   - Tapping it pops open a bottom drawer or quick-select menu allowing instant persona swapping with haptic feedback, without losing draft data or needing to enter passwords.
3. **Adaptive Navigation Architecture**:
   - `BottomBar.tsx` dynamically displays tabs tailored to the persona's statutory authority.
   - 52px thumb target ergonomics (`.field-touch-target`) maintained across all interactive buttons.

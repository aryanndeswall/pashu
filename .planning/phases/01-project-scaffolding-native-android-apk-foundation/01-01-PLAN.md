  <action>
    Install Capacitor 6 core packages and configure the native Android container.
    1. In `mobile/package.json`, install:
       - `@capacitor/core`: ^6.1.0
       - `@capacitor/android`: ^6.1.0
       - `@capacitor/cli`: ^6.1.0 (devDependency)
    2. Create `mobile/capacitor.config.ts` with:
       - `appId`: `"com.pashusuraksha.app"`
       - `appName`: `"Pashu-Suraksha"`
       - `webDir`: `"dist"`
       - `server`: `{ androidScheme: "https" }`
    3. Run `npx --prefix mobile cap add android` to generate the `mobile/android/` Gradle project.
    4. In `mobile/android/variables.gradle` or `mobile/android/app/build.gradle`, verify:
       - `minSdkVersion` = 28 (Android 9.0 Pie)
       - `compileSdkVersion` = 34 (Android 14)
       - `targetSdkVersion` = 34 (Android 14)
    5. Run `npx --prefix mobile cap sync android` to copy the `dist/` web assets into `mobile/android/app/src/main/assets/public/`.
  </action>

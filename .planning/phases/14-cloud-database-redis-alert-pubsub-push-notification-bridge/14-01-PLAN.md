# Plan 14-01: Cloud Database Resilience, Redis Pub/Sub, and Dual-Transport Outbreak Streaming

**Phase:** 14  
**Plan:** 01 of 02  
**Requirement:** `CLOUD-04`  
**Goal:** Implement resilient cloud PostgreSQL connection with local SQLite failover, Redis Pub/Sub outbreak event streaming, and dual-transport real-time delivery (WebSocket & SSE) for Web-GIS command centers.

---

## Proposed Changes

### 1. Database Connectivity & Resilience
- **File [MODIFY]:** `backend/app/database.py`
  - Enhance `create_async_engine` with resilience: attempt cloud `DATABASE_URL` with pre-ping; if connection fails or times out, seamlessly switch to local SQLite.
  - Add `verify_database_connection()` startup health checker.

### 2. Redis Pub/Sub & Streaming Service
- **File [NEW]:** `backend/app/services/pubsub_service.py`
  - Define `OutbreakAlertEvent` schema (cluster_id, syndrome_code, disease, epicenter_lat, epicenter_lon, village_name, district_name, radius_km, alert_level, advisory, timestamp).
  - Build `PubSubService`:
    - Asynchronously connects to Upstash Redis using `redis.asyncio`.
    - Implements in-memory fallback broadcaster if Redis is disconnected.
    - Manages active WebSocket connections (`ConnectionManager`).
    - Exposes `publish_outbreak_event(event)`.
    - Exposes `sse_stream()` asynchronous event generator for SSE clients.

### 3. API Endpoints
- **File [MODIFY]:** `backend/app/api/v1/clusters.py`
  - Add WebSocket endpoint: `@router.websocket("/ws")` allowing real-time bidirectional messaging and broadcast reception.
  - Add SSE endpoint: `@router.get("/stream")` returning `StreamingResponse(sse_stream(), media_type="text/event-stream")`.
  - Add broadcast trigger inside `evaluate_incident` when `requires_containment_buffers` or `OUTBREAK_DECLARED`.
- **File [MODIFY]:** `backend/app/api/v1/sync.py`
  - In `sync_telemetry`, if `containment_triggered`, publish outbreak event to `pubsub_service`.

### 4. Automated Testing
- **File [NEW]:** `backend/tests/test_pubsub.py`
  - Test `PubSubService` event publishing and subscription.
  - Test WebSocket `/api/v1/clusters/ws` connection and event delivery.
  - Test SSE `/api/v1/clusters/stream` output formatting.
  - Test telemetry ingestion triggering pub/sub broadcast.

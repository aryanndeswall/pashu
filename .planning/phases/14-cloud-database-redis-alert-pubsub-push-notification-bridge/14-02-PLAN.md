# Plan 14-02: Firebase Cloud Messaging (FCM), Statutory SMS Bridge, and Web-GIS Alert Banner

**Phase:** 14  
**Plan:** 02 of 02  
**Requirement:** `CLOUD-05`  
**Goal:** Implement automated containment alert dispatch via Firebase Cloud Messaging (FCM) topic broadcast and statutory SMS fallback, connecting Web-GIS dashboards to real-time biosecurity containment directives.

---

## Proposed Changes

### 1. Backend Notification Service
- **File [NEW]:** `backend/app/services/notification_service.py`
  - Implement `NotificationService`:
    - `dispatch_fcm_alert(topic, title, body, data)`: Sends high-priority push message using `firebase_admin.messaging`.
    - `generate_statutory_sms(village, district, syndrome_code, radius_km)`: Formulates statutory legal directive citing Sections 6, 10, 20 of PCICDA 2009.
    - `broadcast_containment_directive(cluster_id, syndrome_code, village, district, radii)`: Orchestrates FCM topic broadcast and SMS generation.
    - Deterministic fallback when Firebase credentials are dummy or unconfigured.

### 2. API Endpoints & Trigger Integration
- **File [MODIFY]:** `backend/app/api/v1/clusters.py`
  - Add `POST /api/v1/clusters/broadcast`: Allows district officials to broadcast statutory containment directives on demand.
  - Wire `broadcast_containment_directive` automatically into `evaluate_incident` when `status == "OUTBREAK_DECLARED"`.
- **File [MODIFY]:** `backend/app/api/v1/sync.py`
  - When `containment_triggered` is True, invoke notification service to dispatch containment directives to the affected jurisdiction.

### 3. Mobile Client Live Alert Integration
- **File [NEW]:** `mobile/src/services/liveAlertService.ts`
  - Connects to `/api/v1/clusters/ws` (with SSE fallback).
  - Listens for `OUTBREAK_ALERT` events and updates alert store.
- **File [MODIFY]:** `mobile/src/components/gis/CommandMapView.tsx` or `DashboardView.tsx`
  - Render an animated real-time biosecurity alert banner when an active containment directive is received.

### 4. Automated Testing
- **File [NEW]:** `backend/tests/test_notifications.py`
  - Test FCM notification payload formulation.
  - Test statutory SMS text generation citing PCICDA 2009.
  - Test broadcast endpoint `/api/v1/clusters/broadcast`.
- **File [NEW]:** `mobile/src/tests/liveAlertStream.test.ts`
  - Test client-side reception and alert state update.

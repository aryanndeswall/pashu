<task type="auto">
  <name>Task 2: Build Animal Registry Models, Schemas, Endpoints & Pytest Suite</name>
  <files>backend/app/models/animal.py, backend/app/schemas/animal.py, backend/app/api/v1/animals.py, backend/tests/conftest.py, backend/tests/test_animals.py</files>
  <read_first>backend/app/database.py, .planning/phases/06-livestock-registry-pashu-aadhaar-cloud-persistence/06-RESEARCH.md</read_first>
  <action>
    1. Create `backend/app/models/animal.py`:
       - `Animal`:
         - `tag_number` (String(12), primary_key=True)
         - `owner_name` (String)
         - `owner_phone_hash` (String(64)) — SHA-256 hash per DPDP Act
         - `owner_phone_masked` (String(20)) — e.g. `+91-XXXXX-9842`
         - `species` (String, e.g. `Bovine`, `Caprine`, `Ovine`)
         - `breed` (String, e.g. `Gir`, `Murrah`, `Osmanabadi`)
         - `age_months` (Integer)
         - `village_lgd_code` (Integer)
         - `created_at` (DateTime, default=func.now())
         - Relationship to `VaccinationRecord`.
       - `VaccinationRecord`:
         - `id` (Integer, primary_key=True, autoincrement=True)
         - `animal_tag` (ForeignKey to `animals.tag_number`)
         - `disease_code` (String, e.g. `FMD`, `LSD`, `ANTHRAX`)
         - `dose_number` (Integer)
         - `administered_at` (DateTime)
         - `next_booster_due` (DateTime)
         - `batch_number` (String)
         - `veterinarian_name` (String)
    2. Create `backend/app/schemas/animal.py`:
       - Pydantic v2 schemas:
         - `AnimalCreate`: validates `tag_number` length == 12 digits, species, breed, village code, raw phone number (automatically converted to hash + masked string).
         - `AnimalResponse`: tag_number, owner_name, owner_phone_masked, species, breed, age_months, village_lgd_code, vaccination_status, vaccinations list.
         - `VaccinationCreate`: disease_code, dose_number, administered_at, batch_number, veterinarian_name.
         - `VaccinationResponse`: id, disease_code, administered_at, next_booster_due, status (`UP_TO_DATE` | `BOOSTER_DUE` | `OVERDUE`).
    3. Create `backend/app/api/v1/animals.py`:
       - `POST /api/v1/animals`: Registers animal, hashes phone, persists to DB.
       - `GET /api/v1/animals/{tag_number}`: Retrieves animal profile with vaccinations.
       - `POST /api/v1/animals/{tag_number}/vaccinations`: Logs vaccination, calculates `next_booster_due` (FMD: +180 days; LSD/Anthrax: +365 days).
       - Mount router onto `app/main.py`.
    4. Create `backend/tests/conftest.py` & `backend/tests/test_animals.py`:
       - Sets up SQLite in-memory async database fixture.
       - Tests registering 12-digit animal and verifies masked phone response.
       - Tests tag lookup returns 404 for nonexistent tag and 200 for registered tag.
       - Tests vaccination logging calculates 180-day booster due date for FMD.
  </action>
  <verify>

  <action>
    1. Create `backend/app/services/satscan_service.py`:
       - Geodesic distance calculation: `calculate_geodesic_distance_meters(lat1, lon1, lat2, lon2) -> float` using Haversine formula.
       - Pre-seeded in-memory census catalog for Ahmednagar district (Ashwi Budruk `558301`, Rahuri Rural `558302`, Sangamner `558303`, Kopargaon `558304`).
       - `evaluate_incident(incident: IncidentCreate, existing_incidents: List[IncidentCreate] = []) -> ClusterEvaluationResponse`:
         - Finds all co-located incidents of the same syndrome within 5,000 meters and reported within 72 hours.
         - Computes cluster epicenter centroid: `(mean(lat), mean(lon))`.
         - Aggregates affected villages LGD codes.
         - Resolves total census population denominator across affected villages.
         - Computes Attack Rate: `(total_affected / total_census) * 100`.
         - Computes Outbreak Probability Score (OPS):
           - If `attack_rate > 1.5` or `total_deaths >= 2`: `status = "OUTBREAK_DECLARED"`, `ops_score = min(0.70 + attack_rate * 0.05, 0.99)`.
           - If `total_affected >= 3`: `status = "WARNING"`, `ops_score = 0.55`.
           - Else: `status = "WATCH"`, `ops_score = 0.25`.
         - Returns complete `ClusterEvaluationResponse`.
    2. Create `backend/tests/test_satscan.py`:
       - Tests geodesic distance between coordinate pairs (Ashwi Budruk to Rahuri).
       - Tests single isolated case returns `WATCH` status (OPS 0.25).
       - Tests 3 cases within 5km in 72h returns `WARNING` (OPS 0.55).
       - Tests 40 affected cattle in Ashwi Budruk (1,450 census -> 2.76% attack rate > 1.5%) triggers `OUTBREAK_DECLARED` with OPS > 0.80.
       - Tests 2 deaths triggers `OUTBREAK_DECLARED` regardless of attack rate.
  </action>
